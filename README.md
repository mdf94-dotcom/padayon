# Padayon

Daily Bisaya (Cebuano) practice for a heritage speaker: spaced review, speed listening, dictation, shadowing, and a voice tutor that hears you, grades you, and remembers the mistakes you repeat.

- Open the app: https://mdf94-dotcom.github.io/padayon/
- Speaking features use your own Gemini API key, stored only in your browser.
- Phrase and word content with native recordings is loaded from a private content pack file on each device; it is not part of this repository.
